# CamRent Backend

The **ASP.NET Core Web API** powering the CamRent ecosystem, managing users, bookings, contracts, and AI-based search.

## 🧩 Tech Stack
- ASP.NET Core 8 Web API
- Entity Framework Core (PostgreSQL)
- Weaviate (Vector Database for semantic search)
- Docker / Railway for deployment

## 🔧 Features
- Authentication & Authorization
- Equipment, Booking, and Contract Management
- Vector search for equipment recommendation
- Feedback and payment handling
- RESTful API endpoints

## 🛠️ Deployment
Containerized via **Docker**, hosted on **Railway**.
